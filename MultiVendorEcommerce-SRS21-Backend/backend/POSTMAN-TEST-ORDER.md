# Postman test order

Import `postman/SRS-21-MultiVendor.postman_collection.json`.

Run the requests in this order:

1. Register Buyer
2. Login Admin
3. Register Vendor Application
4. Admin List Vendors
5. Admin Approve Vendor
6. Login Vendor After Approval
7. List Categories
8. Create Product
9. Add Product Variant
10. Publish Product
11. Search Products
12. Add To Cart
13. View Cart
14. Checkout
15. Capture Mock Payment
16. My Orders

The collection stores JWTs and IDs automatically in collection variables.
